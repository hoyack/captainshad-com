# Content operating notes

## Voice

Calm, specific, and useful under pressure. Prefer verbs, owners, timeboxes, and verification steps. Avoid heroics, war-room theater, certainty claims, and blame language.

## Minimum pattern for each runbook

1. State when to use it.
2. Name the artifact produced.
3. Give an ordered checklist.
4. Include a copy-ready template where useful.
5. End with a verification or exit condition.
6. Link to the Hoyack rescue review without implying guaranteed outcomes.

## Update cadence

Quarterly: test links, review policy dates, confirm incident guidance, and retire stale tool references. After material corrections, add the change to the Corrections page.
